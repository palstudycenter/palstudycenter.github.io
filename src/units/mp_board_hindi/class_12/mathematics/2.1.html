Q.1 Find the value of \[ \sin^{-1}\left(-\frac12\right) \]

उत्तर -

\[ \sin^{-1}\left(-\frac12\right) = -\sin^{-1}\left(\frac12\right) \]

\[ = -\sin^{-1}\left(\sin\frac{\pi}{6}\right) \]

\[ = -\frac{\pi}{6} \]

Q.2 Find the value of \[ \cos^{-1}\left(\frac{\sqrt3}{2}\right) \]

उत्तर -

\[ \cos^{-1}\left(\frac{\sqrt3}{2}\right) =\cos^{-1}\left(\cos\frac{\pi}{6}\right) \]

\[ =\frac{\pi}{6} \]

Q.3 Find the value of \[ \csc^{-1}(2) \]

उत्तर -

\[ \csc^{-1}(2) =\sin^{-1}\left(\frac12\right) \]

\[ =\sin^{-1}\left(\sin\frac{\pi}{6}\right) \]

\[ =\frac{\pi}{6} \]

Q.4 Find the value of \[ \tan^{-1}(-\sqrt3) \]

उत्तर -

\[ \tan^{-1}(-\sqrt3) =-\tan^{-1}(\sqrt3) \]

\[ =-\tan^{-1}\left(\tan\frac{\pi}{3}\right) \]

\[ =-\frac{\pi}{3} \]

Q.5 Find the value of \[ \cos^{-1}\left(-\frac12\right) \]

उत्तर -

\[ \cos^{-1}\left(-\frac12\right) =\cos^{-1}\left(\cos\frac{2\pi}{3}\right) \]

\[ =\frac{2\pi}{3} \]

Q.6 Find the value of \[ \tan^{-1}(-1) \]

उत्तर -

\[ \tan^{-1}(-1) =-\tan^{-1}(1) \]

\[ =-\tan^{-1}\left(\tan\frac{\pi}{4}\right) \]

\[ =-\frac{\pi}{4} \]

Q.7 Find the value of \[ \sec^{-1}\left(\frac{2}{\sqrt3}\right) \]

उत्तर -

\[ \sec^{-1}\left(\frac{2}{\sqrt3}\right) =\cos^{-1}\left(\frac{\sqrt3}{2}\right) \]

\[ =\cos^{-1}\left(\cos\frac{\pi}{6}\right) \]

\[ =\frac{\pi}{6} \]

Q.8 Find the value of \[ \cot^{-1}(\sqrt3) \]

उत्तर -

\[ \cot^{-1}(\sqrt3) =\cot^{-1}\left(\cot\frac{\pi}{6}\right) \]

\[ =\frac{\pi}{6} \]

Q.9 Find the value of \[ \cos^{-1}\left(-\frac{1}{\sqrt2}\right) \]

उत्तर -

\[ \cos^{-1}\left(-\frac{1}{\sqrt2}\right) =\cos^{-1}\left(\cos\frac{3\pi}{4}\right) \]

\[ =\frac{3\pi}{4} \]

Q.10 Find the value of \[ \sec^{-1}(-\sqrt2) \]

उत्तर -

\[ \sec^{-1}(-\sqrt2) =\cos^{-1}\left(-\frac{1}{\sqrt2}\right) \]

\[ =\cos^{-1}\left(\cos\frac{3\pi}{4}\right) \]

\[ =\frac{3\pi}{4} \]

Q.11 Find the value of \[ \tan^{-1}(1)+\cos^{-1}\left(-\frac12\right)+\sin^{-1}\left(-\frac12\right) \]

उत्तर -

\[ \tan^{-1}(1) =\tan^{-1}\left(\tan\frac{\pi}{4}\right) \]

\[ =\frac{\pi}{4} \]

\[ \cos^{-1}\left(-\frac12\right) =\cos^{-1}\left(\cos\frac{2\pi}{3}\right) \]

\[ =\frac{2\pi}{3} \]

\[ \sin^{-1}\left(-\frac12\right) =-\sin^{-1}\left(\frac12\right) \]

\[ =-\sin^{-1}\left(\sin\frac{\pi}{6}\right) \]

\[ =-\frac{\pi}{6} \]

\[ \tan^{-1}(1)+\cos^{-1}\left(-\frac12\right)+\sin^{-1}\left(-\frac12\right) \]

\[ =\frac{\pi}{4}+\frac{2\pi}{3}-\frac{\pi}{6} \]

\[ =\frac{\pi}{4}+\frac{\pi}{2} \]

\[ =\frac{3\pi}{4} \]

Q.12 Find the value of \[ \cos^{-1}\left(\frac12\right)+2\sin^{-1}\left(\frac12\right) \]

उत्तर -

\[ \cos^{-1}\left(\frac12\right) =\cos^{-1}\left(\cos\frac{\pi}{3}\right) \]

\[ =\frac{\pi}{3} \]

\[ \sin^{-1}\left(\frac12\right) =\sin^{-1}\left(\sin\frac{\pi}{6}\right) \]

\[ =\frac{\pi}{6} \]

\[ \cos^{-1}\left(\frac12\right)+2\sin^{-1}\left(\frac12\right) \]

\[ =\frac{\pi}{3}+2\left(\frac{\pi}{6}\right) \]

\[ =\frac{\pi}{3}+\frac{\pi}{3} \]

\[ =\frac{2\pi}{3} \]

Q.13 If \[ \sin^{-1}(x)=y, \] then

(A) \(0\le y\le\pi\)

(B) \(-\dfrac{\pi}{2}\le y\le\dfrac{\pi}{2}\)

(C) \(0

(D) \(-\dfrac{\pi}{2}

उत्तर -

Inverse sine function का principal value सदैव

\[ -\frac{\pi}{2}\le y\le\frac{\pi}{2} \]

अतः सही विकल्प है —

\[ \boxed{(B)\;-\frac{\pi}{2}\le y\le\frac{\pi}{2}} \]

Q.14 Find the value of \[ \tan^{-1}(\sqrt3)-\sec^{-1}(-2) \]

(A) \(\pi\)

(B) \(-\dfrac{\pi}{3}\)

(C) \(\dfrac{\pi}{3}\)

(D) \(\dfrac{2\pi}{3}\)

उत्तर -

\[ \tan^{-1}(\sqrt3) =\tan^{-1}\left(\tan\frac{\pi}{3}\right) =\frac{\pi}{3} \]

\[ \sec^{-1}(-2) =\cos^{-1}\left(-\frac12\right) =\cos^{-1}\left(\cos\frac{2\pi}{3}\right) =\frac{2\pi}{3} \]

\[ \tan^{-1}(\sqrt3)-\sec^{-1}(-2) =\frac{\pi}{3}-\frac{2\pi}{3} \]

\[ =-\frac{\pi}{3} \]

अतः सही विकल्प है —

\[ \boxed{(B)\;-\frac{\pi}{3}} \]
