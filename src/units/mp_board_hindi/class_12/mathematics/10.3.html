Q.1 An urn contains 5 red and 5 black balls. Find the probability that the second ball is red.

Solution

\[ \text{Let }R_1=\text{First ball is red} \]

\[ P(R_1)=\frac{5}{10}=\frac12 \]

\[ \text{Let }B_1=\text{First ball is black} \]

\[ P(B_1)=\frac{5}{10}=\frac12 \]

\[ \text{Let }R_2=\text{Second ball is red} \]

\[ P(R_2|R_1)=\frac{7}{12} \]

\[ (5R+5B\rightarrow7R+5B) \]

\[ P(R_2|B_1)=\frac{5}{12} \]

\[ (5R+5B\rightarrow5R+7B) \]

\[ P(R_2)=P(R_1)P(R_2|R_1)+P(B_1)P(R_2|B_1) \]

\[ =\left(\frac12\right)\left(\frac7{12}\right)+\left(\frac12\right)\left(\frac5{12}\right) \]

\[ =\frac{12}{24} \]

\[ =\frac12 \]

\[ \therefore \text{Required Probability}=\frac12 \]

Q.2 Two bags are given. The first bag contains 4 red and 4 black balls and the second bag contains 2 red and 6 black balls. One bag is selected at random and a red ball is drawn. Find the probability that the first bag was selected.

Solution

\[ \text{Let }E_1=\text{First bag selected} \]

\[ P(E_1)=\frac12 \]

\[ \text{Let }E_2=\text{Second bag selected} \]

\[ P(E_2)=\frac12 \]

\[ \text{Let }R=\text{Red ball drawn} \]

\[ P(R|E_1)=\frac48=\frac12 \]

\[ P(R|E_2)=\frac28=\frac14 \]

\[ \text{Using Bayes' Theorem} \]

\[ P(E_1|R) =\frac{P(E_1)P(R|E_1)} {P(E_1)P(R|E_1)+P(E_2)P(R|E_2)} \]

\[ =\frac{\left(\frac12\right)\left(\frac12\right)} {\left(\frac12\right)\left(\frac12\right)+\left(\frac12\right)\left(\frac14\right)} \]

\[ =\frac{\frac14}{\frac38} \]

\[ =\frac23 \]

\[ \therefore \text{Required Probability}=\frac23 \]

Q.3 A student is selected at random from a class. The probability that the student is a hosteller is 0.6 and the probability that a hosteller obtains grade A is 0.3. The probability that a day scholar obtains grade A is 0.2. If the selected student has obtained grade A, find the probability that the student is a hosteller.

Solution

\[ \text{Let }H=\text{Hosteller} \]

\[ P(H)=0.6 \]

\[ \text{Let }D=\text{Day Scholar} \]

\[ P(D)=0.4 \]

\[ \text{Let }A=\text{Obtains Grade A} \]

\[ P(A|H)=0.3 \]

\[ P(A|D)=0.2 \]

\[ \text{Using Bayes' Theorem} \]

\[ P(H|A)= \frac{P(H)P(A|H)} {P(H)P(A|H)+P(D)P(A|D)} \]

\[ = \frac{0.6\times0.3} {(0.6\times0.3)+(0.4\times0.2)} \]

\[ =\frac{0.18}{0.26} \]

\[ =\frac{9}{13} \]

\[ \therefore \text{Required Probability}=\frac{9}{13} \]

Q.4 A student answers a multiple choice question. The probability that he knows the answer is \(\frac34\). If he does not know the answer, he guesses. Assuming that a question has four choices, find the probability that the student knew the answer, given that he answered it correctly.

Solution

\[ \text{Let }K=\text{Student knows the answer} \]

\[ P(K)=\frac34 \]

\[ \text{Let }G=\text{Student guesses} \]

\[ P(G)=\frac14 \]

\[ \text{Let }C=\text{Correct answer} \]

\[ P(C|K)=1 \]

\[ P(C|G)=\frac14 \]

\[ \text{Using Bayes' Theorem} \]

\[ P(K|C) = \frac{P(K)P(C|K)} {P(K)P(C|K)+P(G)P(C|G)} \]

\[ = \frac{\left(\frac34\right)(1)} {\left(\frac34\right)(1)+\left(\frac14\right)\left(\frac14\right)} \]

\[ = \frac{\frac34} {\frac34+\frac1{16}} \]

\[ = \frac{\frac34} {\frac{13}{16}} \]

\[ = \frac34\times\frac{16}{13} \]

\[ = \frac{12}{13} \]

\[ \therefore \text{Required Probability}=\frac{12}{13} \]

Q.5 A person has a disease with probability \(0.001\). A diagnostic test detects the disease correctly with probability \(0.99\) and gives a false positive with probability \(0.005\). If the test result is positive, find the probability that the person actually has the disease.

Solution

\[ \text{Let }D=\text{Person has disease} \]

\[ P(D)=0.001 \]

\[ P(D')=0.999 \]

\[ \text{Let }T=\text{Positive test} \]

\[ P(T|D)=0.99 \]

\[ P(T|D')=0.005 \]

\[ \text{Using Bayes' Theorem} \]

\[ P(D|T)= \frac{P(D)P(T|D)} {P(D)P(T|D)+P(D')P(T|D')} \]

\[ = \frac{(0.001)(0.99)} {(0.001)(0.99)+(0.999)(0.005)} \]

\[ = \frac{0.00099} {0.005985} \]

\[ \approx0.165 \]

\[ =16.5\% \]

\[ \therefore \text{Required Probability}\approx0.165 \]

Q.6 Three coins are chosen at random from a bag containing one two-headed coin, one biased coin (having probability \(\frac34\) of showing head) and one fair coin. One coin is tossed and it shows a head. Find the probability that it was the two-headed coin.

Solution

\[ \text{Let }E_1=\text{Two-headed coin} \]

\[ P(E_1)=\frac13 \]

\[ \text{Let }E_2=\text{Biased coin} \]

\[ P(E_2)=\frac13 \]

\[ \text{Let }E_3=\text{Fair coin} \]

\[ P(E_3)=\frac13 \]

\[ \text{Let }H=\text{Head} \]

\[ P(H|E_1)=1 \]

\[ P(H|E_2)=\frac34 \]

\[ P(H|E_3)=\frac12 \]

\[ \text{Using Bayes' Theorem} \]

\[ P(E_1|H) = \frac { P(E_1)P(H|E_1) } { P(E_1)P(H|E_1)+P(E_2)P(H|E_2)+P(E_3)P(H|E_3) } \]

\[ = \frac { \left(\frac13\right)(1) } { \left(\frac13\right)(1)+ \left(\frac13\right)\left(\frac34\right)+ \left(\frac13\right)\left(\frac12\right) } \]

\[ = \frac { \frac13 } { \frac13+\frac14+\frac16 } \]

\[ = \frac { \frac13 } { \frac34 } \]

\[ = \frac13\times\frac43 \]

\[ = \frac49 \]

\[ \therefore \text{Required Probability}=\frac49 \]

Q.7 A city has 2000 scooters, 4000 cars and 6000 trucks. The probability of an accident involving a scooter, car and truck is \(0.01,\ 0.03\) and \(0.15\) respectively. One of the vehicles met with an accident. Find the probability that it is a scooter.

Solution

\[ \text{Let }S=\text{Scooter} \]

\[ P(S)=\dfrac{2000}{12000}=\dfrac{1}{6} \]

\[ \text{Let }C=\text{Car} \]

\[ P(C)=\dfrac{4000}{12000}=\dfrac{1}{3} \]

\[ \text{Let }T=\text{Truck} \]

\[ P(T)=\dfrac{6000}{12000}=\dfrac{1}{2} \]

\[ \text{Let }A=\text{Accident} \]

\[ P(A|S)=0.01 \]

\[ P(A|C)=0.03 \]

\[ P(A|T)=0.15 \]

\[ \text{Using Bayes' Theorem} \]

\[ P(S|A) = \dfrac { P(S)P(A|S) } { P(S)P(A|S)+P(C)P(A|C)+P(T)P(A|T) } \]

\[ = \dfrac { \left(\dfrac{1}{6}\right)(0.01) } { \left(\dfrac{1}{6}\right)(0.01)+ \left(\dfrac{1}{3}\right)(0.03)+ \left(\dfrac{1}{2}\right)(0.15) } \]

\[ = \dfrac { 0.001667 } { 0.086667 } \]

\[ \approx0.0192 \]

\[ =\dfrac{5}{260}\approx\dfrac{1}{52} \]

\[ \therefore \text{Required Probability}\approx0.0192 \]

Q.8 A factory has two machines A and B. Machine A produces 60% of the total items and Machine B produces 40%. The percentage of defective items produced by A and B are 2% and 1% respectively. An item selected at random is found to be defective. Find the probability that it was produced by Machine B.

Solution

\[ \text{Let }A=\text{Item produced by Machine A} \]

\[ P(A)=0.60 \]

\[ \text{Let }B=\text{Item produced by Machine B} \]

\[ P(B)=0.40 \]

\[ \text{Let }D=\text{Defective item} \]

\[ P(D|A)=0.02 \]

\[ P(D|B)=0.01 \]

\[ \text{Using Bayes' Theorem} \]

\[ P(B|D) = \dfrac { P(B)\,P(D|B) } { P(A)\,P(D|A)+P(B)\,P(D|B) } \]

\[ = \dfrac { (0.40)(0.01) } { (0.60)(0.02)+(0.40)(0.01) } \]

\[ = \dfrac { 0.004 } { 0.016 } \]

\[ = \dfrac { 1 } { 4 } \]

\[ \therefore \text{Required Probability} = \dfrac { 1 } { 4 } \]

Q.9 Two groups compete for election. The probability that the first group will form the government is 0.6 and the probability that the second group will form the government is 0.4. If the first group forms the government, the probability of introducing a new product is 0.7. If the second group forms the government, the probability of introducing a new product is 0.3. If a new product is introduced, find the probability that the second group formed the government.

Solution

\[ \text{Let }G_1=\text{First group forms the government} \]

\[ P(G_1)=0.6 \]

\[ \text{Let }G_2=\text{Second group forms the government} \]

\[ P(G_2)=0.4 \]

\[ \text{Let }N=\text{New product is introduced} \]

\[ P(N|G_1)=0.7 \]

\[ P(N|G_2)=0.3 \]

\[ \text{Using Bayes' Theorem} \]

\[ P(G_2|N) = \frac { P(G_2)P(N|G_2) } { P(G_1)P(N|G_1)+P(G_2)P(N|G_2) } \]

\[ = \frac { (0.4)(0.3) } { (0.6)(0.7)+(0.4)(0.3) } \]

\[ = \frac { 0.12 } { 0.54 } \]

\[ = \frac29 \]

\[ \therefore \text{Required Probability}=\frac29 \]

Q.10 A girl throws a die. If the die shows 1, 2, 3 or 4, she tosses one coin. If the die shows 5 or 6, she tosses three coins. If exactly one head is obtained, find the probability that the die showed 1, 2, 3 or 4.

Solution

\[ \text{Let }E_1=\text{Die shows }\{1,2,3,4\} \]

\[ P(E_1)=\frac46=\frac23 \]

\[ \text{Let }E_2=\text{Die shows }\{5,6\} \]

\[ P(E_2)=\frac26=\frac13 \]

\[ \text{Let }H=\text{Exactly one head is obtained} \]

\[ P(H|E_1)=\frac12 \]

\[ P(H|E_2)=\binom31\left(\frac12\right)^3=\frac38 \]

\[ \text{Using Bayes' Theorem} \]

\[ P(E_1|H) = \frac { P(E_1)P(H|E_1) } { P(E_1)P(H|E_1)+P(E_2)P(H|E_2) } \]

\[ = \frac { \left(\frac23\right)\left(\frac12\right) } { \left(\frac23\right)\left(\frac12\right)+ \left(\frac13\right)\left(\frac38\right) } \]

\[ = \frac { \frac13 } { \frac13+\frac18 } \]

\[ = \frac { \frac13 } { \frac{11}{24} } \]

\[ = \frac13\times\frac{24}{11} = \frac{8}{11} \]

\[ \therefore \text{Required Probability}=\frac{8}{11} \]

Q.11 A manufacturer has three machine operators A, B and C who produce 50%, 30% and 20% of the total items respectively. The percentages of defective items produced by A, B and C are 1%, 5% and 7% respectively. If an item is selected at random and found to be defective, find the probability that it was produced by operator A.

Solution

\[ \text{Let }A=\text{Item produced by operator A} \]

\[ P(A)=0.50 \]

\[ \text{Let }B=\text{Item produced by operator B} \]

\[ P(B)=0.30 \]

\[ \text{Let }C=\text{Item produced by operator C} \]

\[ P(C)=0.20 \]

\[ \text{Let }D=\text{Defective item} \]

\[ P(D|A)=0.01 \]

\[ P(D|B)=0.05 \]

\[ P(D|C)=0.07 \]

\[ \text{Using Bayes' Theorem} \]

\[ P(A|D) = \frac { P(A)P(D|A) } { P(A)P(D|A)+P(B)P(D|B)+P(C)P(D|C) } \]

\[ = \frac { (0.50)(0.01) } { (0.50)(0.01)+(0.30)(0.05)+(0.20)(0.07) } \]

\[ = \frac { 0.005 } { 0.005+0.015+0.014 } \]

\[ = \frac { 0.005 } { 0.034 } = \frac{5}{34} \]

\[ \therefore \text{Required Probability}=\frac{5}{34} \]

Q.12 One card is lost from a pack of 52 playing cards. From the remaining cards, two cards are drawn and both are found to be diamonds. Find the probability that the lost card was a diamond.

Solution

\[ \text{Let }D=\text{Lost card is a diamond} \]

\[ P(D)=\frac{13}{52}=\frac14 \]

\[ \text{Let }D'=\text{Lost card is not a diamond} \]

\[ P(D')=\frac{39}{52}=\frac34 \]

\[ \text{Let }E=\text{Both drawn cards are diamonds} \]

\[ P(E|D)=\frac{\binom{12}{2}}{\binom{51}{2}} =\frac{66}{1275} \]

\[ P(E|D')=\frac{\binom{13}{2}}{\binom{51}{2}} =\frac{78}{1275} \]

\[ \text{Using Bayes' Theorem} \]

\[ P(D|E) = \frac { P(D)P(E|D) } { P(D)P(E|D)+P(D')P(E|D') } \]

\[ = \frac { \left(\frac14\right)\left(\frac{66}{1275}\right) } { \left(\frac14\right)\left(\frac{66}{1275}\right) + \left(\frac34\right)\left(\frac{78}{1275}\right) } \]

\[ = \frac{66}{66+234} \]

\[ = \frac{66}{300} = \frac{11}{50} \]

\[ \therefore \text{Required Probability}=\frac{11}{50} \]

Q.13 The probability that A speaks the truth is \(\frac45\). A coin is tossed and A reports that a head has appeared. Find the probability that actually a head appeared.

Solution

\[ \text{Let }H=\text{Head appears} \]

\[ P(H)=\frac12 \]

\[ \text{Let }T=\text{Tail appears} \]

\[ P(T)=\frac12 \]

\[ \text{Let }R=\text{A reports Head} \]

\[ P(R|H)=\frac45 \]

\[ P(R|T)=\frac15 \]

\[ \text{Using Bayes' Theorem} \]

\[ P(H|R) = \frac { P(H)P(R|H) } { P(H)P(R|H)+P(T)P(R|T) } \]

\[ = \frac { \left(\frac12\right)\left(\frac45\right) } { \left(\frac12\right)\left(\frac45\right) + \left(\frac12\right)\left(\frac15\right) } \]

\[ = \frac{\frac25}{\frac25+\frac1{10}} = \frac{\frac25}{\frac12} \]

\[ = \frac45 \]

\[ \therefore \text{Required Probability}=\frac45 \]

Q.14 If \(A \subset B\) and \(P(B)\neq0\), then show that \[ P(A|B)\ge P(A). \]

Solution

\[ \text{Given }A\subset B \]

\[ A\cap B=A \]

\[ \text{Using the definition of conditional probability,} \]

\[ P(A|B) = \frac{P(A\cap B)}{P(B)} = \frac{P(A)}{P(B)} \]

\[ \text{Since }A\subset B,\; P(A)\le P(B)\le1 \]

\[ \frac1{P(B)}\ge1 \]

\[ P(A|B) = P(A)\cdot\frac1{P(B)} \ge P(A) \]

\[ \therefore P(A|B)\ge P(A) \]
